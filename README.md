# Wetterdaten-Machine-Learning
In diesem Projekt werden Wetterdaten - Bilder mit Hilfe von Deep Learning und OpenCV analisiert


# Project Requirements
Ein Deep Learning Algorithmus aufzubauen, der aus der Fotos von der Kaggle Image Dataset lernt Bilder von Taghimmel in Wetterkategorien zu Klassifizieren. Die Python Codes und die Theorie dahinter wird auch Schritt für Schritt erklärt.
Die Python Codes und die Erklärungen wurden mit Hilfe von KI (ChatGPT)erstellt.
