# Wetterdaten-Machine-Learning
In diesem Projekt werden Wetterdaten - Bilder mit Hilfe von Deep Learning und OpenCV klassifiziert. 


# Project Requirements
Ein Deep Learning Algorithmus aufzubauen, der aus den Fotos von der Kaggle Image Dataset lernt Bilder in Wetterkategorien zu klassifizieren.

# Objective:
Mein Ziel war ein Machine Learning Projekt in Python basierend auf einen gut erprobten Datensatz zu erstellen und den Code detailliert zu verstehen.
Die Python Codes und die Theorie dahinter wird auch Schritt für Schritt erklärt.
Die Python Codes und die Erklärungen wurden mit Hilfe von KI (ChatGPT)erstellt.


# Verwendung der Dateien

## Der Ordner „scripts“ enthält folgende Dateien:

„Weather_Image_Classification_python.py“:
Vollständiger Python-Code mit Datenaufbereitung, Erstellung eines Convolutional Neural Networks (CNN), Training und Validierung des Modells. Der Code enthält außerdem detaillierte Erläuterungen zu den einzelnen Programmzeilen.

„Weather_Image_Classification_jupyter.ipynb“:
Jupyter-Notebook-Version der oben genannten Datei „Weather_Image_Classification_python.py“.

„import_kagglehub.py“:
Python-Skript zum Herunterladen des Datensatzes und zur Anzeige eines einzelnen Bildes.

„Weather_Image_Classification_Prediction_Of_New_Image.py“:
Python-Code zur Vorhersage der Wetterklasse neuer Bilder mithilfe des zuvor trainierten und validierten CNN-Modells.

Weitere Varianten des Scripts „Weather_Image_Classification_python.py“: Siehe Details in den Präsentation in "reports" 
- "Weather_Image_Classification_EarlyStopping_python"
- "Weather_Image_Classification_EarlyStopping_Data_Augmentation_python"
- "Weather_Image_Classification_EarlyStopping_Data_Augmentation_LR_0005_python"
