# Wetterdaten-Machine-Learning
In diesem Projekt werden Wetterdaten - Bilder mit Hilfe von Deep Learning und OpenCV analisiert. 


# Project Requirements
Ein Deep Learning Algorithmus aufzubauen, der aus der Fotos von der Kaggle Image Dataset lernt Bilder in Wetterkategorien zu klassifizieren.

## Objective:
Mein Ziel war ein Machine Learning Projekt in Python basierend auf gut erprobte Dataset zu erstellen und den Code detailliert zu verstehen.
Die Python Codes und die Theorie dahinter wird auch Schritt für Schritt erklärt.
Die Python Codes und die Erklärungen wurden mit Hilfe von KI (ChatGPT)erstellt.


## Usage of the files:

The scripts folder contains the following files:

"Weather_Image_Classification_python.py":
Complete Python code with data preparation, creating Convolutional Neural Network, training and validation including detaild explanation line by line.

"Weather_Image_Classification_jupyter".ipynb:
Jupyter notebook version of the above mentioned "Weather_Image_Classification_python.py" file.
